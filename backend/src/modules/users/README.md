# Module users

Phụ trách: Người A.

Hồ sơ, địa chỉ, quản lý khách hàng. Chỉ user hiện tại hoặc admin có quyền được truy cập dữ liệu cá nhân.

Khi triển khai, tạo `users.routes.js`, `users.controller.js` và `users.model.js`. Thêm service nếu nghiệp vụ cần. Dùng `require/module.exports`; mount router trong `src/app.js`. Xem catalog để tham khảo MVC và `docs/team-guide.md` để thống nhất API.

Hợp đồng hiện hành: [backend-contract.md](../../../docs/backend-contract.md).
