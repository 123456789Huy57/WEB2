# Module vouchers

Phụ trách: Người B.

Voucher và usage; kiểm tra lại trong checkout, không tin mức giảm gửi từ Angular.

Khi triển khai, tạo `vouchers.routes.js`, `vouchers.controller.js` và `vouchers.model.js`. Thêm service nếu nghiệp vụ cần. Dùng `require/module.exports`; mount router trong `src/app.js`. Xem catalog để tham khảo MVC và `docs/team-guide.md` để thống nhất API.

Hợp đồng hiện hành: [backend-contract.md](../../../docs/backend-contract.md).
