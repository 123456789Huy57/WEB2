# Module vouchers

Phụ trách: Người B. Quản lý voucher, voucher người dùng đã lưu và lượt sử dụng. Quote và checkout kiểm tra lại điều kiện và số lượt; không tin mức giảm gửi từ Angular.

Routes áp dụng quyền theo endpoint, controller nối HTTP với service; service thực hiện kiểm tra và ghi usage trong transaction.

Hợp đồng hiện hành: docs/backend-contract.md.
