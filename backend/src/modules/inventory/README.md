# Module inventory

Phụ trách: Người B.

Mọi thao tác tăng/giảm stock và hoàn kho. Thống nhất với A để API sửa Product không ghi đè tồn kho.

Khi triển khai, tạo `inventory.routes.js`, `inventory.controller.js` và `inventory.model.js`. Thêm service nếu nghiệp vụ cần. Dùng `require/module.exports`; mount router trong `src/app.js`. Xem catalog để tham khảo MVC và `docs/team-guide.md` để thống nhất API.

Hợp đồng hiện hành: [backend-contract.md](../../../docs/backend-contract.md).
